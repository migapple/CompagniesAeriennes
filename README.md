NOTES POUR LA REVUE APPLE (App Review Information › Notes)
---------------------------------------------------------------------
This is a native SwiftUI app (MapKit 3D globe, Swift Charts) that works offline. Only the My Apps tab uses the network (public iTunes Lookup API) to show the developer's other apps.
Airlines are shown with app-generated monograms (IATA codes) only; no airline or alliance logos are used.
The app is independent and not affiliated with any airline or alliance.
